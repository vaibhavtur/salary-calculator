# Employee Salary Calculator (React + Vite)

## Run
    npm install
    npm run dev

Open the URL shown in the terminal (usually http://localhost:5173).

## Files
- src/App.jsx - form, datewise salary logic, salary slip
- src/index.css - colourful UI styles
- salary-calculator-standalone.html - single-file version, open directly in a browser (needs internet for React CDN)

## Edit wages
Change the POSITIONS object at the top of src/App.jsx.
